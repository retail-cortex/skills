# Retail Cortex Java Skills (`retailcortex-skills-java`)

[![PyPI Version](https://img.shields.io/pypi/v/retailcortex-skills-java.svg)](https://pypi.org/project/retailcortex-skills-java/)
[![Python Version](https://img.shields.io/badge/python-3.13%2B-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/license-Apache%202.0-blue.svg)](LICENSE)

Retail Cortex enterprise AI agent skills for Java 21+, Maven, Javalin, Hibernate, and SpotBugs rulesets.

## Bundled Skills

- `java-enterprise`: Enterprise Java Maven layout, Javalin, Hibernate, Weld, and Checkstyle rules.
- `java-project-setup`: Automated setup for Java projects.

## Installation

```bash
pip install retailcortex-skills-java
```

Or using `uv`:

```bash
uv add retailcortex-skills-java
```
