# Retail Cortex Python Skills (`retailcortex-skills-python`)

[![PyPI Version](https://img.shields.io/pypi/v/retailcortex-skills-python.svg)](https://pypi.org/project/retailcortex-skills-python/)
[![Python Version](https://img.shields.io/badge/python-3.13%2B-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/license-Apache%202.0-blue.svg)](LICENSE)

Retail Cortex enterprise AI agent skills for Python 3.13, FastAPI, Google ADK, and FastMCP.

## Bundled Skills

- `python-core`: Core Python 3.13 packaging, `uv`, type hinting, and testing standards.
- `python-project-setup`: Automated setup patterns for new Python services.
- `python-fastapi`: Enterprise FastAPI routing, schemas, and async patterns.
- `python-adk-fastapi`: Integrating Google Agent Development Kit with FastAPI endpoints.
- `python-fastmcp`: FastMCP server creation and tool definitions.

## Installation

```bash
pip install retailcortex-skills-python
```

Or using `uv`:

```bash
uv add retailcortex-skills-python
```
