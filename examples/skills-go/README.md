# Retail Cortex Go Skills (`retailcortex-skills-go`)

[![PyPI Version](https://img.shields.io/pypi/v/retailcortex-skills-go.svg)](https://pypi.org/project/retailcortex-skills-go/)
[![Python Version](https://img.shields.io/badge/python-3.13%2B-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/license-Apache%202.0-blue.svg)](LICENSE)

Retail Cortex enterprise AI agent skills for Go microservice architectures and project scaffolding.

## Bundled Skills

- `go-lang`: Go directory structure, distroless Docker builds, golangci-lint, and test rules.
- `go-project-setup`: Automated workspace scaffolding for Go projects.

## Installation

```bash
pip install retailcortex-skills-go
```

Or using `uv`:

```bash
uv add retailcortex-skills-go
```
