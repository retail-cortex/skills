# Retail Cortex Frontend Skills (`retailcortex-skills-frontend`)

[![PyPI Version](https://img.shields.io/pypi/v/retailcortex-skills-frontend.svg)](https://pypi.org/project/retailcortex-skills-frontend/)
[![Python Version](https://img.shields.io/badge/python-3.13%2B-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/license-Apache%202.0-blue.svg)](LICENSE)

Retail Cortex enterprise AI agent skills for React 19, Vite, Module Federation, and Material 3 design systems.

## Bundled Skills

- `react-vite`: React 19 component architecture, Vite bundler setup, and Material 3 design integration.

## Installation

```bash
pip install retailcortex-skills-frontend
```

Or using `uv`:

```bash
uv add retailcortex-skills-frontend
```
