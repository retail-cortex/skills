# Retail Cortex A2A Skill Package (`retailcortex-skills-a2a`)

[![PyPI Version](https://img.shields.io/pypi/v/retailcortex-skills-a2a.svg)](https://pypi.org/project/retailcortex-skills-a2a/)
[![Python Version](https://img.shields.io/badge/python-3.13%2B-blue.svg)](https://www.python.org/)
[![License](https://img.shields.io/badge/license-Apache%202.0-blue.svg)](LICENSE)

Retail Cortex Agent-to-Agent (A2A) protocol AI agent skill definitions compatible with Google ADK.

## Installation

```bash
pip install retailcortex-skills-a2a
```

Or using `uv`:

```bash
uv add retailcortex-skills-a2a
```
